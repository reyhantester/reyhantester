# Project Name: [mobupps]

This project is an automated testing suite built with Cypress to ensure the stability and functionality of the application.

---

## 📋 Prerequisites
Before you begin, ensure you have the following installed on your local machine:
* **Node.js** (v18.0.0 or higher)
* **npm** (usually comes with Node.js)
* **WebStorm** or any preferred IDE

---

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone <https://github.com/reyhantester/reyhantester>
   cd <mobupps>

    1-1. Install Dependencies: This will install Cypress and all required libraries listed in package.json 
      npm install
    1-2.Open Cypress UI (Interactive Mode):
      npx cypress open
    1-3.Run Tests in CLI
      npx cypress run
